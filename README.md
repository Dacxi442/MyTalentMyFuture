# #MyTalentMyFuture

A single-page narrative and registration portal for a 3-day children's talent-discovery bootcamp charity.

## Development

You need [Bun](https://bun.sh/) installed to run this project.

```sh
bun install
bun run dev
```

## Tech Stack

- React
- Vite
- Tailwind CSS
- Radix UI
- TanStack Router

- TanStack Start
- TypeScript
- React
- Tailwind CSS
